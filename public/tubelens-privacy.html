Privacy Policy

Effective date: 14 October 2026

TubeLens is an independent tool that visualises your YouTube viewing patterns. It is not affiliated with or endorsed by YouTube or Google. This policy explains what the current version of TubeLens processes when you use the dashboard or optionally connect a Google account.

Watch-history imports

When you choose a Google Takeout watch-history.json file, TubeLens reads and analyses it in your browser using a Web Worker. The file and the resulting viewing statistics stay in the active browser tab's memory; they are not uploaded to the TubeLens server, Google, or an analytics service. Refreshing or closing the tab clears this in-memory history data, so you must import the file again to use it in a new session.

Google account and YouTube subscriptions

Connecting your account is optional. If you connect, TubeLens requests the read-only YouTube permission youtube.readonly. It uses the YouTube Data API to retrieve your subscribed-channel list and the channel details returned with those subscriptions, so it can compare subscriptions with the history you imported. TubeLens does not use the YouTube Data API to retrieve your personal watch history, and it does not receive your Google password.

OAuth credentials are kept on the TubeLens server, in memory, and are not sent to your browser as tokens. The browser receives an HTTP-only session cookie containing a random session identifier. The local session expires after up to eight hours. Subscription results are cached temporarily in server memory (normally reused for five minutes and cleared by periodic cleanup); restarting the server clears its in-memory sessions and cache.

How data is used and shared

Google subscription data is used only to provide the subscription list and related comparisons shown in TubeLens. TubeLens does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. We do not send imported watch-history files or their calculated analytics to third parties.

The page loads Chart.js from jsDelivr and web fonts from Google Fonts. Channel thumbnails, when displayed, may load from Google/YouTube image servers. These providers may receive ordinary connection information from your browser, such as your IP address and the requested asset URL; TubeLens does not send your imported history file or chart statistics to them. The hosting provider may also process basic technical request logs under its own policies, and the server writes diagnostic messages for OAuth or API errors.

TubeLens's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Retention, sign-out and deletion

TubeLens does not save imported watch history or subscription data to a database in the current version. The server holds OAuth credentials and subscription cache only in memory for the temporary session described above. Selecting Disconnect attempts to revoke the Google credentials and removes the local session and subscription cache. Because revocation is an online request, it may fail; you can also revoke access in your Google Account connections.

Since imported history is not uploaded, there is no server-side copy of that file for TubeLens to delete. Closing or refreshing the tab clears it from the active page. Hosting-provider technical logs may be retained according to that provider's settings and policies.

Security and choices

You can use demo mode and import history without connecting Google. The server uses a temporary session, and OAuth tokens are not exposed to frontend JavaScript. No internet service can guarantee absolute security; keep your browser and devices secure, and do not share your Takeout export.
